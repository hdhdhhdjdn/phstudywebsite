# 错题站 · 使用说明

一个纯本地的错题 / 知识点 / Mark Scheme 管理工具。不需要联网、不需要装数据库，数据存在你自己的浏览器里。

---

## 一、怎么打开

### 方式 A（推荐，最简单）：双击单文件版

双击 **`错题站.html`** 即可。文件本身包含全部代码，也可以直接发给同学（每人各用各的数据）。

> 数据存在浏览器（Edge / Chrome）的 IndexedDB 里，换浏览器或清浏览数据会丢，**记得定期导出题库包**。

### 方式 B（备用）：本地服务

如果方式 A 打开后顶部出现黄色/红色警告（数据库不可用），双击 **`启动（本地服务）.cmd`**。
它会开一个黑色窗口并自动打开 `http://localhost:8765/`，**关闭那个黑窗口 = 关闭服务**。

> 方式 B 需要电脑上有 Node.js。本机已带（脚本里写死了路径，找不到时会回退到 `node`）。

### 方式 C：班级版（账号 + 全班共享题库）

双击 **`启动（班级版）.cmd`**，注册账号后使用；同学在同一 WiFi 下打开 `http://你的IP:8765/` 即可登录。
详见第七节。

## 二、五个核心模块

### 1. 错题本

- **+ 新增错题**：只需要「题干」或「一张题目图片」，**答案可以留空**——批改时 AI 会生成标准答案并写回题库。
- 答案区默认收起，需要手填时点「▸ 已有答案？展开填写」。
- 每题记录：科目、来源、日期、知识点标签、题干、我的答案、正确答案、Mark Scheme 得分要点、错因、难度、状态、笔记。
- **错因标签**：`K 知识` / `M 方法` / `C 计算` / `E 表达`，可多选。
- **Mark Scheme 要点**：每条可以勾「漏了」，专门用来复盘"会但拿不到分"。
- 顶部可以按科目 / 知识点 / 错因 / 状态筛选，也能搜索。
- 每道题默认**只显示题目**，题目下方点 **「👀 查看答案」** 才展开正确答案和 Mark Scheme 要点（再点收起，适合自测）。
- **图片题可以一键转文字**：配置好 AI 密钥后，带图的题目卡片上会出现 **「🔤 转文字」**，点一下由 AI 识别成题干文字（公式用 Unicode 符号）。
  转完后**原图自动收起**，需要时点 **「🖼 查看原图」** 展开；图片不会被删除。
- 「打印」会生成适合打印的错题清单（浏览器打印对话框 → 另存为 PDF，打印时答案会自动展开）。
- **班级版**：题库全班共享，别人新上传的题点右上角「刷新」就能看到。

### 2. 知识点

- 每个知识点一张卡：定义、公式/关键规则、易错点。
- 错题里打的标签会自动和知识点关联，点「相关错题 N 道」直接跳回筛选结果。

### 3. Mark Scheme

- 把所有错题里的得分要点集中摊开。
- 勾「只看考试时漏掉的」就能得到一张"我反复漏的关键词清单"。

### 4. 收件箱（和同学协作的中转站）

**用途**：同学发来的题目照片先放这里，**不直接进题库**；导出成「待转录包」交给 AI 转成文字，转录结果再导回来。

流程：

1. 同学把题目照片发到班级群 → 你（或他）把图片放进「收件箱」（可多选，也可以直接把图片拖进这个页面）
2. 点 **「导出待转录包 .zip」**
3. 把 zip 发给 AI 转录（AI 会返回一个「题库包」）
4. 回到网站点 **「导入转录结果」** → 题目进「错题本」，收件箱里对应的图自动清理

**包格式（AI 转录时用）**

```
待转录-YYYY-MM-DD.zip
├─ inbox.json      { "format":"cuoti-inbox", "version":1,
│                    "entries":[{ "id","subject","uploader","note","image":"inbox/<id>.jpg" }] }
└─ inbox/<id>.jpg
```

AI 返回的结果包：

```
转录结果.zip
├─ library.json         { "format":"cuoti-library", "version":1, "items":[...], "topics":[...] }
├─ inbox-resolved.json  { "format":"cuoti-inbox-resolved", "resolved":["<inbox id>", ...] }
└─ images/<newid>.jpg   （如果题目图片要保留）
```

### 5. 作答 / 批改（做题 → AI 出标准答案 → 判分）

**流程**：

1. 在「错题本」任意题目卡片上点 **✍️ 作答**，卡片里会展开一个**答题框**（就地写，不用跳弹窗）
2. 写下你的答案（可以写完整解题过程），点「提交作答」
3. 到「作答 / 批改」页，两种方式任选：
   - **复制粘贴（文字题推荐）**：点「复制待批改」→ 粘贴到聊天发给 AI → AI 返回结果 → 点「粘贴批改结果」粘贴、应用
   - **批改包（图片题）**：点「导出批改包 .zip」发给 AI → 收到结果后「导入批改包」
4. 结果会**直接显示**在两个地方：
   - 「作答 / 批改」页的作答卡片
   - **错题本里那道题的卡片下方**（当前账号最近一次批改：得分、参考答案、逐点命中/缺失、点评、错因）
5. 如果这道题原来没有标准答案，会自动写回题库，以后别人做同一题就有答案了

**包格式**

```
批改包-YYYY-MM-DD.zip
├─ grading.json   { "format":"cuoti-grading", "version":1,
│                   "submissions":[{ "id","questionId","subject","studentName",
│                                   "questionText","answerText","currentCorrectAnswer",
│                                   "currentMarkScheme":[...],"imageIds":[...] }] }
└─ images/<id>.jpg   （题目有图时附带）

批改结果.zip（AI 返回）
├─ grades.json    { "format":"cuoti-grades", "version":1,
│                   "results":[{ "submissionId","standardAnswer","score","fullMarks",
│                                "points":[{ "point","awarded","max","comment" }],
│                                "causes":["K","C"],"comment":"…" }] }
```

## 三、复习

- 「复习」页显示今天到期的题数；「开始复习」按遗忘曲线抽题。
- 先只看题干，自己回忆 → 点「显示答案」→ 对照正确答案和每个得分点 → 选择：
  - 😵 **忘了**：明天再来
  - 😐 **有点难**：间隔拉长一些
  - 😎 **记住了**：间隔翻倍，连续记住 3 次自动标记「已掌握」

## 四、数据和共享

| 操作 | 位置 | 说明 |
|---|---|---|
| 导出题库包 `.zip` | 设置 | 含图片，发给同学可互相导入合并 |
| 导出 JSON | 设置 | 只含文字，体积小，适合快速备份 |
| 导出待转录包 `.zip` | 收件箱 | 把待转录图片打包，交给 AI |
| 导入转录结果 / 题库包 | 设置 或 收件箱 | 自动识别 zip 里的 library.json |
| 载入示例数据 | 设置 | 化学月考的 9 道错题 + 8 个知识点 |
| 清空全部数据 | 设置 | 不可恢复，先导出 |

**和同学一起用（当前，离线版）**：各自在本地用，互发 `.zip` 题库包；题目收集走「收件箱 → AI 转录 → 导入」。
**升级路线（以后）**：等流程跑顺，再升级成"公网站点"（后端 + 数据库 + 上传接口），做到多人同时在线、随时访问。

## 五、常见问题

**Q：数据存在哪里？安全吗？**
存在这台电脑当前浏览器的 IndexedDB 里，不上传任何服务器。

**Q：换了浏览器/电脑，数据还在吗？**
不在。先「导出题库包」，在新环境「导入」。

**Q：浏览器清缓存会丢吗？**
会。清"网站数据"会删掉 IndexedDB。定期导出备份。

**Q：图片太大怎么办？**
录入时会自动压缩到最长边 1500px 的 JPEG，正常一张题目照片约 200–400KB。

**Q：可以几个人共用一个文件夹吗？**
可以，但要注意：数据不在文件夹里，而在各自的浏览器里。共享靠题库包。

## 六、班级版（账号 + 全班共享题库）

> 这是给"一个班 30–50 人、题库共享、同学各自上传"准备的版本。**离线版继续保留**，两者数据格式互通。

### 怎么启动

双击 **`启动（班级版）.cmd`** → 会自动开服务器并打开 `http://localhost:8765/`。

- 同学在**同一 WiFi** 下，用浏览器打开控制台里打印的 `http://192.168.x.x:8765/` 就能用；
- 关闭那个黑色窗口 = 停止服务。

### 账号规则

- **开放注册**：登录页点「注册」即可；
- **第一个注册的账号自动成为管理员**（建议你先注册，拿到管理员权限）；
- 用户名 2–24 位小写字母/数字/下划线，密码至少 4 位；
- 密码用 `scrypt` 加盐哈希存储，会话是 HttpOnly Cookie。

### 权限

| 角色 | 能做什么 |
|---|---|
| 学生 | 看全班共享题库、新增自己的题、编辑/删除自己的题、提交收件箱、复习 |
| 管理员 | 以上全部 + 编辑/删除任何人的题 + 查看所有人的收件箱 + 导出/导入题库包 + 备份 |

### 数据在哪

- `cloud-data/db.json`：账号、错题、知识点、收件箱
- `cloud-data/uploads/`：题目图片
- 备份：管理员调 `GET /api/admin/backup`（后续会在「设置」里加按钮）

### 接口一览（开发/排查用）

```
GET  /api/health              健康检查（前端用它判断云端模式）
POST /api/register            注册
POST /api/login               登录
POST /api/logout              退出
GET  /api/me                  当前用户
GET/POST /api/items           共享错题（POST 建，PUT /:id 改，DELETE /:id 删）
GET/POST /api/topics          知识点
GET/POST /api/inbox           收件箱（学生只看自己的，管理员看全部）
GET/POST /api/submissions     作答记录（学生只看自己的，管理员看全部）
POST /api/images/upload?id=   上传图片（原始字节）
GET  /api/images/:id          读取图片
GET  /api/users               用户列表（管理员）
PATCH /api/users/:id          改角色/禁用（管理员）
GET  /api/admin/backup        全库备份（管理员）
```

### 已知限制（下一步会改）

1. **掌握状态是共享的**：题库共享，但"已掌握/复习中"应该每人独立，下一步会拆成每人一份进度；
2. **批改是人工触发的**：需要你导出批改包发我，不能上传后自动出分（那是 API 版）；
3. **没有密码重置**：忘了密码目前只能管理员直接改数据库文件；
4. **公网访问**：目前只支持局域网。要真正"随时访问"，需要部署到云（约 ¥10/月 的国内学生机，或免费海外平台但不稳定）。

## 七、让网站一直开着

### 方案 A：本地常驻（电脑开着就行）

| 双击 | 作用 |
|---|---|
| `启动（后台运行）.cmd` | 无窗口后台启动，日志写入 `server.log` |
| `安装开机自启.cmd` | 加入 Windows 启动项，开机自动运行 |
| `停止服务器.cmd` | 停止占用 8765 端口的服务 |
| `取消开机自启.cmd` | 移除开机自启 |

注意：**电脑睡眠 = 断网**，请把电源设置改成"插电时从不睡眠"。

### 方案 B：公网部署（推荐，电脑关机也能用）

把网站放到云服务器（学生机约 ¥10/月），全班随时随地可访问，不再依赖谁的电脑开着。

**完整步骤见 [`deploy/部署说明.md`](deploy/部署说明.md)**，概要：

1. 买服务器（1 核 2G、Ubuntu 22.04），安全组放行 `TCP 8765`
2. 在 `cuoti-site` 目录运行 `deploy\上传到服务器.ps1 -Server 你的IP`
3. 服务器上运行 `PORT=8765 REGISTER_CODE=你的邀请码 bash deploy.sh`
4. 浏览器打开 `http://你的公网IP:8765/`，第一个注册的账号就是管理员

> `REGISTER_CODE` 是注册邀请码，公网部署建议一定要设置（不设任何人都能注册）。

### 方案 B2：Vercel 部署（免服务器，但国内访问不一定稳）

如果同学能在 Vercel 上部署、并且能买域名，可以用 **Vercel 版**：

- 部署包：`错题站-Vercel部署包.zip`
- 说明：[`deploy/vercel部署说明.md`](deploy/vercel部署说明.md)
- 架构：Vercel 静态托管 + Serverless 函数 + **Vercel KV**（数据）+ **Vercel Blob**（图片）
- ⚠️ 必须连接 KV 和 Blob，否则数据存在内存里会丢（「设置 → 存储状态」会显示 `memory ⚠️`）
- ⚠️ `*.vercel.app` 在大陆经常打不开，**务必绑定自己的域名**并实测

## 八、文件结构（开发用）

```
cuoti-site/
├─ 错题站.html              ← 离线单文件版（build-single.js 生成，可直接发送）
├─ index.html               ← 入口（自动判断：file:// 用本地库，http 用云端）
├─ login.html               ← 班级版登录/注册页
├─ css/style.css
├─ js/zip.js                ← 题库包 ZIP 读写（store 模式）
├─ js/db.js                 ← 本地 IndexedDB 封装
├─ js/api.js                ← 云端客户端 + 存储适配层（Cloud.store）
├─ js/seed.js               ← 示例数据（化学月考）
├─ js/app.js                ← 全部界面逻辑（本地/云端共用）
├─ build-single.js          ← 打包离线单文件：node build-single.js
├─ server.js                ← 纯静态本地服务（可选）
├─ cloud-server.js          ← 班级版服务器（账号 + 共享题库 + 作答批改 + 图片）
├─ 启动（本地服务）.cmd
├─ 启动（班级版）.cmd
├─ 启动（后台运行）.cmd      ← 无窗口后台启动
├─ 安装开机自启.cmd / 取消开机自启.cmd / 停止服务器.cmd
├─ start-hidden.vbs         ← 后台启动的实现（日志写 server.log）
├─ deploy/
│  ├─ deploy.sh             ← 云服务器一键部署（Node + systemd + 防火墙）
│  ├─ 上传到服务器.ps1       ← Windows 端 scp 上传
│  └─ 部署说明.md            ← 买服务器到上线的完整步骤
├─ cloud-data/              ← 运行时生成：db.json + uploads/
└─ test/
   ├─ zip.test.js           ← ZIP 往返 / CRC32
   ├─ dom-check.js          ← id 引用、data-action、打包入口静态检查
   └─ cloud-api.test.js     ← 班级版 API：注册/登录/权限/UTF-8 往返
```

**改完代码后重新打包单文件**：

```bash
node build-single.js
```

**跑测试**：

```bash
node test/zip.test.js
node test/dom-check.js

# 先启动班级版服务器，再跑：
node test/cloud-api.test.js http://localhost:8765
```
