# 域名配置：shphstudy.cc → Vercel

目标：`https://shphstudy.cc`（主域名）和 `https://www.shphstudy.cc` 都能访问，且自动 HTTPS。
Vercel 在境外，**不需要 ICP 备案**；域名本身需完成注册商要求的实名认证。

## 1. Vercel 添加域名

1. Vercel → 项目 → **Settings → Domains**
2. 输入 `shphstudy.cc` → Add
3. 再输入 `www.shphstudy.cc` → Add
4. 在域名列表里把 `shphstudy.cc` 设为 **Primary**（另一个会自动 301 跳转过来）

## 2. DNS 解析（在你的域名注册商 / DNS 服务商处配置）

| 类型 | 主机记录 | 记录值 | 说明 |
|---|---|---|---|
| A | `@` | `76.76.21.21` | 根域名指向 Vercel |
| CNAME | `www` | `cname.vercel-dns.com` | www 指向 Vercel |
| TXT | `_vercel` | Vercel 页面显示的验证值 | 若 Vercel 提示需要验证时添加 |

注意：
- **保留原有的 MX / TXT 邮箱记录**，不要覆盖
- 若用 Cloudflare 托管 DNS：记录先设为 **DNS only（灰色云朵）**，等 Vercel 签发证书成功后再考虑开启代理（代理模式需 SSL 设为 Full）
- 若 Vercel 显示其他 IP/目标值（不同项目可能不同），以页面提示为准

## 3. 生效与验证

- DNS 生效通常 5 分钟–2 小时（最长 48 小时）
- Vercel Domains 页面会显示 `Valid Configuration` 并自动签发 Let's Encrypt 证书
- 验证：
  ```bash
  nslookup shphstudy.cc
  nslookup www.shphstudy.cc
  curl -I https://shphstudy.cc
  ```
  `curl` 返回 `200` / `301` / `308` 且证书有效即成功。

## 4. 应用层无需改动

- 前端所有请求都用相对路径 `/api/...`，绑定域名不影响
- `vercel.json` 不需要写域名；域名在 Vercel 后台管理
- 本地使用的 `http://localhost:8765` 不受影响

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 显示 `Invalid Configuration` | DNS 未生效或记录值不对；检查 A / CNAME 是否与页面一致 |
| 访问跳转到 Vercel 默认域名 | 在 Domains 里把 `shphstudy.cc` 设为 Primary |
| `www` 打不开 | CNAME 记录缺失或被 CNAME 冲突（根域名不能有 CNAME） |
| 证书一直在签发中 | DNS 未生效；Cloudflare 代理需先关掉（灰色云朵） |
| 国内访问慢/偶发打不开 | Vercel 香港区域已设；可换网络或后续考虑国内服务器（需备案） |

## 6. 如果以后改用国内服务器

`shphstudy.cc` 解析到中国大陆服务器**必须完成 ICP 备案**（约 1–3 周），否则会被拦截；在此之前继续用 Vercel 即可。
