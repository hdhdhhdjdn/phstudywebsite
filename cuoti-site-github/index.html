使用提示

  • 数据只存在这台电脑的浏览器里（IndexedDB），换电脑请先导出题库包。
  • 题干可以只贴图片；图片支持 Ctrl+V 粘贴截图。
  • 复习时先自己回忆，再点「显示答案」，最后按 忘了 / 有点难 / 记住了 安排下次。
  • 「Mark Scheme」页把每道题的得分要点摊开，专治"会但拿不到分"。
